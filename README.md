## Brand Switcher
Switches Minecraft's Client Brand...

This branch is the 1.7.10 Forge backport. It needs [UniMixins](https://github.com/LegacyModdingMC/UniMixins).

## Usage
`/brandswitcher`, or the Config button in the mod list, opens the config screen.
